# Шпаргалка для збирача (телефон)

## Перед виходом у під’їзд (є інтернет)

1. Відкрий **OSBB Збір**.
2. Введи свій **Telegram ID** → Увійти.
3. Обери **ЖК → будинок → під’їзд**.
4. Натисни **1. Завантажити підʼїзд**.
5. Дочекайся повідомлення «Завантажено … лічильників».

## У під’їзді (інтернет не потрібен)

1. Натисни **2. Обхід офлайн**.
2. На екрані: поверх, квартира, тип лічильника, попередній показник.
3. Введи новий показник → **Зберегти**.
4. Якщо мешканець уже подав — можна **Прийняти самостійний**.
5. Якщо стрибок великий — підтверди або введи ще раз.
6. **Пропустити** — якщо немає доступу / не знімаєш зараз.

## Після обходу (знову є інтернет)

1. Повернись на головний екран.
2. Натисни **3. Вивантажити покази**.
3. Переконайся, що «Чекають вивантаження: 0».

## Якщо щось пішло не так

| Проблема | Що робити |
|---|---|
| Немає доступу | Перевір Telegram ID; адмін має видати права в боті |
| Не вантажить під’їзд | Перевір інтернет і адресу сервера (кнопка «Адреса сервера») |
| Обхід порожній | Спочатку зроби крок 1 — Завантажити |
| Вивантаження з помилкою | Збережи телефон увімкненим, спробуй знову при кращому зв’язку. Покази не зникають з телефону |

## Важливо

- Покази спочатку лише в телефоні. Поки не натиснув **Вивантажити** — у боті / ДАХ їх ще немає.
- Не видаляй додаток і не чисти дані, поки не вивантажив.
- Один під’їзд = один цикл: завантажити → зняти → вивантажити.
