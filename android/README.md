# OSBB Meter Collector (Android)

Офлайн-додаток для збору показників лічильників з двосторонньою синхронізацією.

## Як працює

1. **Увійти** — лише свій Telegram ID (права як у боті).
2. **1. Завантажити підʼїзд** — тягне лічильники в телефон (потрібен інтернет).
3. **2. Обхід офлайн** — знімаєте покази без мережі.
4. **3. Вивантажити покази** — коли знову є інтернет.

Додаток памʼятає останній ЖК / будинок / підʼїзд.

## Відкрити проєкт

1. Встанови [Android Studio](https://developer.android.com/studio).
2. **Open** → папка `android/` цього репозиторію.
3. Дочекайся Gradle sync.
4. Запусти на емуляторі або телефоні.

## Підключення до API

| Девайс | API URL (кнопка «Адреса сервера») |
|---|---|
| Емулятор Android | `http://10.0.2.2:8787/` |
| Телефон у тій же Wi‑Fi | `http://<IP-компʼютера>:8787/` |
| Прод-сервер | `https://your-domain/` |

На сервері в `.env`:

```env
MOBILE_API_PORT=8787
```

Запуск API:

```bash
npm run api
```

Або бот + API:

```bash
npm run dev
```

## Права доступу

Логін перевіряє `TelegramUser` + `UserAccess` у PostgreSQL.  
Хто вже є в боті з доступом до ЖК — той увійде в додаток. Нових користувачів додаток **не створює**.
