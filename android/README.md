# OSBB Meter Collector (Android)

Офлайн-додаток для збору показників лічильників з двосторонньою синхронізацією.

## Як працює

1. **Увійти** — Telegram ID + `MOBILE_API_KEY` + URL API.
2. **⬇ Синхронізувати (завантажити)** — тягне квартири/лічильники/попередні покази під’їзду в локальну Room-БД.
3. **▶ Почати обхід офлайн** — прохід без інтернету, покази зберігаються локально.
4. **⬆ Синхронізувати (вивантажити)** — відправляє локальні покази в PostgreSQL як `COLLECTED`.

## Відкрити проєкт

1. Встанови [Android Studio](https://developer.android.com/studio).
2. **Open** → папка `android/` цього репозиторію.
3. Дочекайся Gradle sync.
4. Запусти на емуляторі або телефоні.

## Підключення до API

| Девайс | API URL |
|---|---|
| Емулятор Android | `http://10.0.2.2:8787/` |
| Телефон у тій же Wi‑Fi | `http://<IP-компʼютера>:8787/` |
| Прод-сервер | `https://your-domain/` |

На сервері в `.env` обовʼязково:

```env
MOBILE_API_KEY=придумай-секретний-ключ
MOBILE_API_PORT=8787
```

Запуск API (окремо від бота):

```bash
npm run api
```

Або разом з ботом:

```bash
npm run dev
```

## Права доступу

Використовується той самий `TelegramUser` / `UserAccess`, що й у боті. Якщо користувач бачить ЖК у Telegram — побачить і в додатку.
